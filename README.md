# 1. 網站建置說明
Swish 是一個由多平台多模型 AI 協作，利用 ASP.NET Core 提供前後端服務的網站。遊戲介面利用 HTML、CSS、JavaScript 和 Canvas 製作；伺服器用 C# 處理帳號、成績、金幣與商店資料，並存進 PostgreSQL。

## 採用 GitOps 自動化部署：

1. 版本控制：使用 GitHub 作為主要程式碼託管與版本管理平台。
2. 自動化託管：使用 Render 雲端平台，設定 Git 觸發機制。
    當程式碼被推送到 GitHub 主分支(`git push origin main`)，Render 會自動捕捉變更並啟動 Build & Deploy 流程。
    自動執行環境變數載入、套件安裝（`npm install`）與服務重啟，確保線上版本實時同步。

## C# 伺服器與 API
API 和遊戲頁由同一個 ASP.NET Core 網站提供。註冊**增加 Cloudflare Turnstile 人機驗證**。
## 資料庫
利用 Neon 平台建置 PostgreSQL 資料庫。Entity Framework Core 負責 C# 程式與 PostgreSQL 之間的資料存取，Npgsql 為連接套件。
玩家頭像使用固定的 `AvatarId` 儲存於 `AspNetUsers`，圖檔放在 `wwwroot/game/avatars`；個人資料 API 只接受預先定義的頭像 ID，不接收使用者上傳檔案。
## Render 部署
Render 使用專案根目錄的 Dockerfile 建置網站。render.yaml 設定服務使用 Docker、健康檢查路徑，以及部署環境需要的變數名稱。



# 2. 遊戲玩法
可選擇 30、60 或 180 秒賽制後開始挑戰。用滑鼠或手指按住球，上下控制力道，左右控制方向，有虛線輔助瞄準，調整後放開投球。遊戲會稍微輔助接近正確的投籃角度和力道。倒數從第一球出手後開始，每命中三球，籃框會開始左右移動、距離也會改變。
## 得分方式
- 一般命中：10 分
- 連續命中第 3 球起，每球增加 10 分 Combo 加分，加分最多 40 分
- Combo 達 5 球起，該球得分 x2
- 球沒有碰到籃框或籃板，且接近籃框中心空心入網：基礎分改為 50 分
例如：一般連進第 1、2 球各 10 分；第 3 球 20 分；第 4 球 30 分；第 5 球開始有雙倍加成，第 6 球起單球最高 100 分。空心球也能再疊加 Combo 分，沒投進會把目前 Combo 歸零。
## 金幣獲取
註冊帳號即可獲得 500 金幣。 金幣計算：每 10 分換 1 金幣，單場最多 100 金幣。
## 排行榜
排行榜依照三種賽制區分，分為 30 秒、60 秒、180 秒，各自記錄每位玩家在該賽制的最高成績，公開榜單最多顯示前 20 名。需登入並成功儲存比賽紀錄，成績才會進入排行榜。
